# SMS Vault Architecture Implementation

Implementing a Simple, Minimal, and Searchable (SMS) Obsidian vault setup that requires zero community plugins and relies exclusively on native core features.

### Objectives
- [x] Configure Unique Note Creator (`zk-prefixer`) for timestamp filenames (`YYYYMMDDHHmm`).
- [x] Establish universal note and tag hub templates using native `aliases` for searchability.
- [x] Build tag-driven views powered by native Obsidian Bases (excluding `Views/` directory).
- [x] Adopt native Obsidian piped link convention: `[[filename|label]]`.
- [x] Route media and assets into `Attachments/`.
