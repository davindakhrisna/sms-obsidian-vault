# Obsidian Core Bases Syntax Reference

Obsidian Bases allows database-like views directly in markdown or standalone `.base` files using native Obsidian features.

### Code Block Syntax
````markdown
```base
filters:
  and:
    - file.hasTag("tag_name")
    - not:
        - file.inFolder("Views")

properties:
  aliases:
    displayName: "Label"

views:
  - type: table
    name: "View Name"
    order:
      - file.name
      - aliases
      - created
```
````

### Key Directives
- `file.hasTag("name")`: Matches tags in both YAML properties and body text.
- `not:` with `file.inFolder("Views")`: Excludes hub notes in `Views/` from query results.
- `properties.aliases.displayName: "Label"`: Renders the `aliases` property column as "Label".
