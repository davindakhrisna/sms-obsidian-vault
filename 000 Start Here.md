# SMS Vault Quickstart

A **Simple, Minimal, Searchable** vault running on **100% Obsidian Core**. Zero community plugins required.

### 1. Create a Note
- Click the **Create unique note** ribbon icon (`Ctrl/Cmd+P` → *New unique note*).
- Notes get a permanent timestamp ID (e.g. `202610290640.md`).

### 2. Name & Tag
- In frontmatter, set **`aliases`** to your note title: `aliases: [My Note Title]`.
- Add flat tags: `tags: [idea, project]`.

### 3. Fast Linking
- Type `[[` and start typing your note title.
- Obsidian searches the alias and auto-inserts: `[[YYYYMMDDHHmm|My Note Title]]`.

### 4. Daily Journal
- Click the **Daily note** ribbon icon (`Ctrl/Cmd+P` → *Open today's daily note*).
- Generates `Journal/YYYY-MM-DD.md` using the Journal template.

### 5. Browse via Views
- Open `Views/` (`inbox`, `idea`, `project`, `reference`, `journal`) to browse auto-filtered tables powered by native **Obsidian Bases**.
