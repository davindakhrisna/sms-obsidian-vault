# Atomic Notes and Flat Organization

Hierarchical folders force notes into rigid categories before their true relationships are understood. By keeping notes flat and using unique IDs:

1. Filenames never need to change when a note's context evolves.
2. Tags provide multi-dimensional classification without duplicating files.
3. Links form organic connections across domains.
