# Obsidian SMS Vault Template

> **Simple. Minimal. Searchable.**  
> A pragmatic Zettelkasten-inspired vault running on **100% native Obsidian core**. Zero community plugins. Zero maintenance.

---

## ⚡ The 1-Minute Workflow

1. **Create Note**: Click the **Unique Note** ribbon icon to stamp a permanent ID (`YYYYMMDDHHmm.md`).
2. **Name It**: Put your note title in `aliases: [Your Note Title]`.
3. **Tag It**: Add flat tags (e.g. `tags: [idea]`, `tags: [project]`).
4. **Link It**: Type `[[Your Title]]` — Obsidian searches aliases and inserts `[[YYYYMMDDHHmm|Your Title]]`.
5. **Daily Journal**: Click the **Daily Note** ribbon icon to open `Journal/YYYY-MM-DD.md`.
6. **Browse**: Open `Views/` to see auto-filtered tables powered by native **Obsidian Bases**.

---

## 📁 Vault Structure

- `/` — Flat content notes with permanent timestamp IDs
- `Journal/` — Daily logs (`YYYY-MM-DD.md`)
- `Views/` — Tag hubs embedding native Obsidian Bases
- `Templates/` — Universal, Tag Hub, and Journal templates
- `Attachments/` — Auto-routed destination for images and media

---

## 🚀 Getting Started

1. Clone or download this repository.
2. In Obsidian: **Open folder as vault** → select this repository directory.
3. Everything is pre-configured and ready to use out of the box.
